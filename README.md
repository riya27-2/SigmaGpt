# SigmaGPT 🤖

SigmaGPT is an AI chatbot application built using the MERN stack and Google Gemini AI. It provides a ChatGPT-like experience with AI conversations and stored chat history.

## 🚀 Features

- AI chatbot using Gemini API
- Real-time AI responses
- Chat history management
- Thread-based conversations
- Responsive user interface

## 🛠️ Tech Stack

**Frontend**
- React.js
- Vite
- CSS
- React Context API

**Backend**
- Node.js
- Express.js
- MongoDB
- Mongoose
- Google Gemini API
